Android 14 (Xperia Ace III) & APK アプリ化 ガイド

実機で確実に1時間毎の通知を受け取るための設定手順

1

Chromeブラウザ / PWA で通知を受信する

  • Android14の通知権限許可: Xperia Ace IIIのChromeで本ページを開き、上部の「通知許可リクエスト」を押してポップアップを許可します。
  • ホーム画面に追加 (PWA化): Chromeメニュー（右上3点）から「ホーム画面に追加」を選択すると、通常のアプリと同じように起動できます。
  • バッテリー最適化の解除 (重要): Android 14 の設定 → 「アプリ」 → 「Chrome」または本アプリ → 「バッテリー」 → 「制限なし (Unrestricted)」 に変更してください。（省電力でバックグラウンド実行が停止するのを防止します）
2

既存の Gradle 環境で APK化する手順

すでにAndroid Studio環境（gradlew）をお持ちの場合、以下の方法で即座にAPKへ組み込めます：

  • WebView組み込み: `MainActivity.kt` の `WebView` に本HTMLを読み込ませるだけでそのままアプリ化できます。
  • TWA (Trusted Web Activity): Bubblewrap CLI 等を利用すると、本WebサイトをそのままビルドしてAPKを作成できます。
  • バックグラウンド1時間通知 (WorkManager): Android Nativeで完全なバックグラウンド通知を行う場合、`WorkManager` の `PeriodicWorkRequest` を1時間周期 (`1, TimeUnit.HOURS`) でセットします。
// Android Studio (Gradle) - WorkManager での1時間毎のバックグラウンド通知の基本構成例
val hourlyNotificationWork = PeriodicWorkRequestBuilder<HourlyNotificationWorker>(
    1, TimeUnit.HOURS
).build()

WorkManager.getInstance(context).enqueueUniquePeriodicWork(
    "HourlyNotifierTask",
    ExistingPeriodicWorkPolicy.KEEP,
    hourlyNotificationWork
)
